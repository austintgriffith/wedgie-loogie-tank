# wedgie-loogie-tank

Loogies swimming on a [wedgie](https://wedgie.dev).

- Joystick: pick a loogie (its number shows). Press: bubbles.
- Save `tank`: `{"loogies": [["op", 7, "4fc822", 81, 188], ["eth", 7, "062200", 49, 0]]}`
  (chain, id, color, chubbiness, mouthLength). No save: demo loogies.
- Loogies (mainnet) `0xE203cDC6011879CDe80c6a1DcF322489e4786eB3`,
  OptimisticLoogies (Optimism) `0x006eB613cc586198003a119485594ECbbDf41230`.

Try it: wedgie.dev/code, Open a folder (or this repo).

Not signed by wedgie.dev: installed from this repo it runs with full access to your wedgie.
